# Как открыть и сохранить Jer Salamat

## Основные ссылки

- Сайт для демонстрации: https://jer-salamat.vercel.app/
- Репозиторий с кодом: https://github.com/Nurchik228/jer-salamat
- Исходный код: https://github.com/Nurchik228/jer-salamat/tree/main/src
- Презентация: [Jer_Salamat_Pitch.pdf](Jer_Salamat_Pitch.pdf)

Репозиторий уже находится в аккаунте Nurchik228. Повторно загружать проект не нужно. Сайт на Vercel и код на GitHub — отдельные вещи: сохранённый код позволяет восстановить сайт, даже если адрес демонстрации перестанет работать.

## Посмотреть код без установки программ

1. Открой репозиторий.
2. Нажми папку `src`.
3. Выбери файл — GitHub покажет его содержимое.
4. Главная страница — `src/pages/LandingPage.tsx`, анкета — `src/pages/QuestionsPage.tsx`, результаты — `src/pages/ResultsPage.tsx`.
5. Расчёты находятся в `src/core`, переводы — в `src/i18n`.

## Скачать запасную копию

В репозитории нажми **Code → Download ZIP**. Распакуй архив и сохрани его на ноутбуке. ZIP содержит файлы выбранной версии, но не всю историю Git. Для копии с историей используй клонирование ниже.

## Запустить на ноутбуке

Понадобятся Git, Node.js с npm и редактор кода, например VS Code. Версия Node.js должна соответствовать требованиям зависимостей в `package-lock.json`. Если npm сообщает `EBADENGINE`, проверь требуемую версию в сообщении и обнови Node.js.

Открой терминал в папке, где хочешь хранить проект:

```bash
git clone https://github.com/Nurchik228/jer-salamat.git
cd jer-salamat
npm ci
npm run dev
```

Открой локальный адрес, который напечатает терминал. Пока работаешь с сайтом, терминал должен оставаться открытым. Для остановки нажми **Ctrl+C**.

При следующих запусках открой терминал в папке `jer-salamat` и выполни `npm run dev`. Двойной щелчок по `index.html` не заменяет запуск через Vite.

Если скачал ZIP, открой терминал внутри распакованной папки проекта и начни с `npm ci`.

## Проверить изменения

```bash
npm run typecheck
npm run lint
npm run i18n:check
npm run build
```

Эти команды предусмотрены в проекте. Их наличие не означает, что проверка уже выполнена для каждой новой версии.

## Как использовать в портфолио

Давай две ссылки: на сайт и на репозиторий. Презентация уже лежит в папке `docs`.

Указывай, что это командный прототип для NASA Space Apps Challenge, и описывай свой вклад: исследование культур и севооборота, координация, проверка пользовательского сценария, подготовка и защита проекта на английском. Не представляй весь командный код как исключительно свою работу.

Чтобы показать проект на главной странице профиля GitHub, открой свой профиль, найди **Customize your pins**, выбери `jer-salamat` и сохрани выбор.

## Важное о сохранении

- Изменения файлов только на ноутбуке не появляются на GitHub автоматически: их нужно закоммитить и отправить через Git или GitHub Desktop.
- Изменение репозитория обновляет сайт автоматически только при настроенной связи этого репозитория с Vercel.
- Не удаляй репозиторий или проект Vercel, если хочешь сохранить доступ по текущим ссылкам.
- История коммитов позволяет посмотреть предыдущие версии.
